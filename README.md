# Чаты WhatsApp

Текстовый мессенджер WhatsApp через [GREEN-API](https://green-api.com).

## Локальный запуск

```bash
npm install
```

Создайте файл `.env` в корне проекта:

```
VITE_API_URL=<ваш-api-url>
```

Это адрес API по умолчанию. Его можно не указывать на экране входа.

```bash
npm run dev
```

Откройте http://localhost:5173.

## Использование развернутого приложения

1. В кабинете GREEN-API скопируйте `idInstance`, `apiTokenInstance` и `apiUrl`. Инстанс должен быть авторизован в WhatsApp.
2. Введите их на экране входа и нажмите «Войти».
3. Нажмите «+» и укажите номер в международном формате, например `79991234567`.
4. Напишите сообщение и отправьте.

Входящие сообщения появляются сами. Данные входа и переписка хранятся в этом браузере. Сменить аккаунт или выйти можно в «Настройках».
